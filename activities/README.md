# Activities

Three activities. The case is the input to the Module 2 discussion; the other two
use the red test suite.

| Activity | When | Brief | Produces |
|---|---|---|---|
| Prompt-first failure | Module 1, 8 min | `m1-exercise.md` | Nothing — you reset the repo |
| Activity 1 — draft and judge | Module 2, 5 min | `activity-1-discussion.md` | A paper draft; no file |
| Hands-on | Module 3, 50 min | `m3-hands-on.md` | Six green exercise tests, no test file touched |

## The case

`cases/case-01-first-order.md` — a growth ticket, not a specification. Groups
draft three sections of the PRD and one ADR decision from it in five minutes,
then compare with the finished sample in the deck.
